# Project context

- At the start of work on this repository, read `Documentation/PROJECT_PROGRESS.md` for the current project handoff. Treat it as a summary, not proof that a feature works; check source and Unity when necessary.
- After completing a meaningful project change, update that file with the outcome, any verification performed, and the next step. Do not mark untested work as tested or infer completion from uncommitted files alone.
- Preserve unrelated local changes; the Unity working tree may contain work in progress.
