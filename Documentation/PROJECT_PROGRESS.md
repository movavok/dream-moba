# Dream MOBA — project handoff

Updated: 2026-11-14

## Documented prototype state

According to `README.md`, this is an active Unity/C# online 3v3 MOBA prototype focused on multiplayer and combat. The README lists a lobby for up to six players, teams, the playable Guitarist, abilities and passives, combat/status effects, respawning, projectiles, building occlusion, map, UI/audio settings, and reusable hero systems. These are documented features, not a fresh end-to-end gameplay verification.
